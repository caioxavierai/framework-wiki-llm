# Editor de notas

> Ferramenta fictícia: o editor em que a wiki é aberta e navegada; o agente escreve, você lê.

## O que é

Um editor de Markdown com visualização de grafo. É opcional: a wiki é só uma pasta de arquivos `.md`, e qualquer editor (ou o próprio terminal) serve.

## Como usamos

- Abrimos a pasta da wiki como "cofre" e navegamos pelos links entre páginas.
- A escrita é do agente; o editor serve para **ler** e para enxergar a forma do grafo.
- Ao ler o índice de uma área, aplicamos o [índice em dois níveis](../conceitos/indice-em-dois-niveis.md): abrimos só o que interessa.
